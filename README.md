# 기능 소개
## 자동 번역
→ 지정한 채널에 설정한 언어 이외의 대화가 입력되면 자동으로 번역합니다.
→ 번역된 내용은 한 채널에만 출력이 가능하며, 번역을 시도할 채널은 여러군데 지정이 가능합니다.

## 핫딜 알리미
→ 핫딜 채널의 신규 소식을 실시간으로 가져옵니다.
→ 지정된 채널에 정기적인 소식을 받아볼 수 있습니다.

## 루비야
→ LLM에게 질문을 하면 답변을 받을 수 있습니다.
→ 지정된 메인 채널에서 답변이 출력됩니다.
→ Gemini 3.5를 기반으로 하기 때문에 부정확한 답변을 받을 수도 있습니다.

## 스타세이비어 공지알림
→ 모바일 게임 [스타세이비어]의 공지 사항을 구독할 수 있는 기능입니다.
→ 공식 라운지의 신규 게시글을 기준으로 가져오나, 매커니즘 수정 예정입니다.

## 알림
→ 정해진 일시, 혹은 특정 시간 이후에 멘션 알림을 받아볼 수 있는 기능입니다.
→ 지정된 메인 채널에서 알림이 출력됩니다.
